# Продолжение кругового облёта

Цель — три последовательных 15-секундных участка, объединённых в один компактный 45-секундный ролик. Игровое замедление до 90 секунд на круг должно выполняться через `playbackRate = 0.5`; исходные ролики не растягиваются.

## Сохранённые материалы

- `segment-01-source.mp4` — первый новый участок облёта, исходный ответ `alibaba/wan-3.0-prime` через OpenRouter, без перекодирования.
- `segment-01.json` — промпт, параметры, идентификатор задания, стоимость и контрольная сумма.
- `segment-02-first.png` — последний кадр первого участка, подготовленный как первый кадр второго.

Исходный ролик фактически имеет размер 1174 × 782 и 30 кадров/с, несмотря на запрос 720p/16:9, и содержит аудио, несмотря на `generate_audio: false`. Игровой экспорт должен сохранять пропорции изображения и удалять аудио.

## Статус

Первый участок сгенерирован за $2,10. Запрос второго участка отклонён OpenRouter с HTTP 403 `Key limit exceeded (daily limit)`. Второй и третий участки пока не созданы. Эти материалы ещё не подключены к игре; существующий фон сохранён до завершения полного облёта.
