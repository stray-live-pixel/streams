# Жилой домик из Blender

Модель по [согласованному концепту](../house-reference-v1/concept.png): светлая штукатурка, деревянный каркас, объёмная терракотовая черепица, каменное основание, окна, дверь с кольцом и цветочный ящик. Участок травы из референса не дублируется: дом ставится на игровой рельеф.

- Источник: [cottage-house.blend](cottage-house.blend), сцена `Cottage house studio`, коллекция `Cottage house geometry`.
- [Лёгкое Eevee-превью](preview.png), Workbench: [спереди](view-front.png), [сзади](view-back.png), [справа](view-right.png), [сверху](view-top.png).
- [Генератор](build_cottage.py) создаёт отдельную сцену в Blender; [финализация](finalize_cottage.py) удаляет из новой копии посторонние сцены, проверяет геометрию и делает быстрые превью. Исходный файл порта не меняется.
- [Экспорт](export_runtime.py) сохраняет только вычисленные меши домика в [OBJ](cottage-house.obj) и [MTL](cottage-house.mtl), без студии, света и камер.
- [Аудит](model-audit.json): 297 мешей, 5 900 вершин, 10 582 треугольника; нулевых треугольников и объёмных деталей с обратным обходом нет. Декоративные лепестки и подложки скатов намеренно открыты.

Blender: Z вверх, фасад −Y, основание около Z=0. OBJ: Y вверх, фасад +Z. Исходная ширина 4,76; экспорт масштабируется на 0,25, затем применяется настройка дома 0,7. Итоговая ширина около 0,83, участок остаётся 1×1. Точка дыма в OBJ — `(1.15, 5.24, -0.72)` до масштабирования.

Игра использует `custom/cottage-house` для всех четырёх вариантов жилых домов, включая существующие сохранения. Цвета MTL переводятся из linear RGB в sRGB, авторские нормали и разметка материалов сохраняются. Штукатурка, дерево и крыша получают игровую рисованную фактуру. Отдельные картинки-текстуры модели не требуются.

Повторный экспорт выполняется из открытого `cottage-house.blend` скриптом `export_runtime.py`. Для повторного построения: запустить `build_cottage.py` в Blender, затем в фоне `Blender --background cottage-house.blend --python finalize_cottage.py`, открыть полученный файл и выполнить экспорт. Пути в скриптах указывают на рабочую папку проекта.

Геометрия и игровой вид проверены технически; окончательная художественная оценка новой 3D-модели остаётся за владельцем.
