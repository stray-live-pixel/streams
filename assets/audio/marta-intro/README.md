# Вступительное письмо Марты

Голос — Lily, модель `elevenlabs/eleven-v4`, генерация через OpenRouter. Голос выбран для более зрелого, мягкого образа Марты. Интонационные теги задают спокойный рассказ с ностальгией и надеждой; дополнительный фильтр `atempo=0.9` замедляет речь на 10% без изменения высоты голоса. Текст сохранён полностью из раздела «Вступление» в [сюжетной концепции](../../../docs/story.md).

- `full.mp3` — готовая полная дорожка, 107,27 секунды, с секундной паузой после каждого абзаца.
- `source.json` — параметры и результаты исходной генерации, длительности сегментов и идентификаторы запросов; раздел `render` описывает замедление и готовые дорожки.
- `phrases.json` — точный текст генерации с аудиотегами для интонаций.
- `frame-01.mp3` … `frame-11.mp3` — отдельные кадры из сохранённых WAV-сегментов новой генерации Lily, обработанные `atempo=0.9`. Суммарно 96,27 секунды речи; время ожидания между кадрами выбирает игрок.
- `frames.json` — названия кадров, субтитры, имена MP3 и длительности речи. Режиссёрские теги в субтитры не попадают.

`scripts/pack-intro.mjs` упаковывает кадры в `.generated/intro.json`. Приложение использует один аудиоэлемент и меняет его источник только при переходе; конец записи не запускает следующий кадр. Сеть для просмотра не нужна.

На экране реплики представлены отдельными бумажными страницами с анимацией перекладывания. Названия из `frames.json` остаются служебными и не показываются. Счётчик `N/11` расположен по центру строки управления; переходы выполняются кнопками или стрелками. Иконки управления берутся из `lucide-react` и включаются при сборке как SVG; React не нужен во время игры.

Портрет создан встроенным инструментом `image_gen`: [исходный PNG](../../art/marta-portrait-source.png), [WebP для игры](../../art/marta-portrait.webp), [точный промпт и параметры](../../art/marta-portrait.json). Прозрачность сохранена. WebP получен командой:

```sh
cwebp -q 90 assets/art/marta-portrait-source.png -o assets/art/marta-portrait.webp
```

Проверки вступления: `node tests/intro.mjs` после сборки; они также включены в `npm run test:e2e`.
