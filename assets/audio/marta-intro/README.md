# Вступительное письмо Марты

Голос — Matilda, модель `elevenlabs/eleven-v4`, генерация через OpenRouter. Повествовательная подача: тёплая и неторопливая, с ностальгией в воспоминаниях и надеждой в финале. Текст сохранён полностью из раздела «Вступление» в [сюжетной концепции](../../../docs/story.md).

- `full.mp3` — исходная полная дорожка, 92,92 секунды, с секундной паузой после каждого абзаца.
- `source.json` — параметры и результаты исходной генерации, длительности сегментов и идентификаторы запросов.
- `phrases.json` — точный текст генерации с аудиотегами для интонаций.
- `frame-01.mp3` … `frame-11.mp3` — отдельные кадры из сохранённых WAV-сегментов той же генерации, без повторной озвучки. Суммарно 81,92 секунды речи; время ожидания между кадрами выбирает игрок.
- `frames.json` — названия кадров, субтитры, имена MP3 и длительности речи. Режиссёрские теги в субтитры не попадают.

`scripts/pack-intro.mjs` упаковывает кадры в `.generated/intro.json`. Приложение использует один аудиоэлемент и меняет его источник только при переходе; конец записи не запускает следующий кадр. Сеть для просмотра не нужна.

Портрет создан встроенным инструментом `image_gen`: [исходный PNG](../../art/marta-portrait-source.png), [WebP для игры](../../art/marta-portrait.webp), [точный промпт и параметры](../../art/marta-portrait.json). Прозрачность сохранена. WebP получен командой:

```sh
cwebp -q 90 assets/art/marta-portrait-source.png -o assets/art/marta-portrait.webp
```

Проверки вступления: `node tests/intro.mjs` после сборки; они также включены в `npm run test:e2e`.
