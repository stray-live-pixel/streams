# Окружение острова

Авторские модели «Тихой Гавани», созданные для проекта 11 октября 2026 года.

- `models.json`: девять готовых мешей и палитра для игры.
- `*.glb`: те же модели для импорта в Blender и другие 3D-инструменты.
- `in-game-preview.png`: настоящий скриншот набора в игровой сцене.
- Генератор: `node scripts/create-nature-models.mjs` из корня игры. Рендер не запускается.
- Оси: Y вверх, X/Z по земле. Основание каждой модели в нуле.
- Источник визуального направления: `assets/art/island-reference.png`.
- Учёт моделей и полигонов: `docs/models.md` и `assets/art/models.json`.

Без текстур, rig, анимаций и сетевой загрузки. В игровом окружении все экземпляры объединены в статическую геометрию, затенение рассчитано в цветах вершин. Права на авторскую геометрию — у проекта; сторонних моделей при создании этого набора не использовано.
