# Требования и причины механик

Эта таблица фиксирует договорённости текущей итерации. Новая механика начинается с обновления требования, затем кода и подходящей проверки.

| ID | Требование | Причина | Где реализовано и проверено |
| --- | --- | --- | --- |
| R01 | Время меняется только кнопкой дня | Игроку нужно спокойно читать обучение | `domain/game.ts`, тест первого рейса |
| R02 | Пять учебных действий: порт, дом, ферма, магазин, день | Начать с понятной последовательности | `domain/tutorial.ts`, browser-тест |
| R03 | Игрок сам выбирает размещение, даже в обучении | Персонализация с первого шага | `domain/game.ts`, тест свободной планировки |
| R04 | Порт бесплатный, один, на берегу с выходом в море | У прибытия людей должно быть понятное место | `domain/world.ts`, тест порта |
| R05 | Деревянные дороги бесплатны; повторный клик удаляет участок; поверх дороги можно строить | Сделать город живее без сложной инфраструктурной экономики | `domain/game.ts`, тест дорог |
| R06 | Дом вмещает 10 человек; сам по себе не создаёт жителей | Люди должны прибывать, а не появляться мгновенно | `domain/catalog.ts`, тест свободной планировки |
| R07 | В начале дня прибывает до 10 человек при наличии мест и порта | Понятный, наблюдаемый рост города | `domain/game.ts`, тесты первого/повторного рейса |
| R08 | Подход, высадка и отход корабля занимают 7 секунд; нельзя запустить второй день в это время | Не допустить наложения рейсов и двойного дохода | `scene/voyage.ts`, unit и browser-тесты |
| R09 | Нет свободных мест — нет рейса | Анимация должна соответствовать изменению населения | тест пустого рейса |
| R10 | Ферма даёт 20 еды; житель ест 1 и приносит 1 монету; ратуша даёт 20; магазин даёт 40, если все накормлены | Минимальная экономика без налогов, энергии и дерева | `domain/economy.ts`, тест экономики первого дня |
| R11 | 50 жителей, неотрицательный баланс еды и 300 монет открывают действие «Зажечь маяк»; оно списывает 300 и завершает историю | Явный финал по решению игрока, а не незаметная смена текста | `domain/story.ts`, тест полного прохождения и E2E финала |
| R12 | Сброс — видимая кнопка с подтверждением | Начать заново, не потеряв город случайным кликом | `ui/index.ts`, browser-тест |
| R13 | Сохранения ранних версий загружаются, жители не пропадают | Развитие проекта не должно уничтожать прогресс | `domain/state.ts`, тест миграции |
| R14 | Готовый HTML работает без сети и без сборки у игрока | Передавать игру как обычный файл | `scripts/build.mjs`, offline browser-тест |
| R15 | В Git остаются полные скачанные наборы ассетов | Неиспользованные модели пригодятся позже | `assets/`, `AGENTS.md`; упаковщик только читает исходники |
| R16 | Интерфейс — письма Марты и отдельные карточки без общей нижней полосы | Более игровой и нарративный вид | `ui/template.html`, `ui/styles.css`, скриншоты проверки |
| R17 | Исходники — строгий TypeScript, команда и состояние имеют явные контракты | Ошибки взаимодействия модулей видны до запуска | `domain/types.ts`, `tsconfig.json`, проверка типов при сборке |
| R18 | Сцена использует Babylon.js; палитра UI задаётся CSS-переменными | Дальнейшее развитие и единый стиль | `scene/`, `ui/theme.css`, E2E с проверкой непустого первого кадра |

| R19 | Финальное письмо с днём основания; после него доступна свободная игра | Сохранить результат и дать ощущение завершения | `ui/`, `endingSeen` в сохранении, тест перезагрузки |
| R20 | Гавань — крупный комплекс, расширенный в море | Порт должен соответствовать масштабу города без удаления старых построек | `scene/harbor.ts`, тест всех береговых клеток |
| R21 | Разные дома, мельницы, лавки, гуляющие жители и дым | Читаемые назначения зданий и ощущение обжитого города | `geometry.ts`, `life.ts`, визуальная проверка |

## Уточнения текущей реализации

- Новые жители учитываются в доходе и потреблении того же дня. На первом учебном утре получается +70 монет и +10 еды.
- Недостаток еды останавливает доход магазинов, но не уменьшает население. Смертность и отъезд сейчас не реализованы.
- Дороги не влияют на доступность зданий и не являются маршрутом пешеходов.
- Рейс отображает уже применённое событие. Перезагрузка завершает визуальный показ, не отменяя заселение.
- Сохранение локальное: синхронизации между компьютерами и браузерами нет.

- Старая победа из версии 3 сохраняется: маяк достраивается без повторного списания монет. Новые игры требуют явного действия.
- Победа не отменяется, если после финала игрок увеличил население быстрее производства еды.
- Жители на улицах декоративные, в ограниченном количестве; они не изображают полноценную логистику. При `prefers-reduced-motion` прогулки и дым отключаются.
