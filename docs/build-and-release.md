# Сборка, проверка и выпуск

## Входы и выходы

```text
assets/* + assets/manifest.json
           ↓ scripts/pack-assets.mjs
.generated/models.json + .generated/card-art.json
           ↓ проверка TypeScript → src/main.ts → esbuild
встроенный JavaScript + src/ui/theme.css + src/ui/styles.css + src/ui/template.html
           ↓ scripts/build.mjs
 dist/index.html и index.html (одинаковое содержимое)
```

`assets/` — исходники, `.generated/` — промежуточный результат, `dist/` — пакет для передачи. Сборка не скачивает ассеты и не меняет их. Зависимости заранее устанавливаются `npm ci`; `package-lock.json` фиксирует версии.

Корневой `index.html`, `.generated/` и `dist/` исключены из Git. Сборка по-прежнему обновляет корневой файл, сохраняя привычный путь запуска и локальные сохранения пользователя. В репозитории хранятся исходники, инструменты сборки и все ассеты; готовый HTML передаётся отдельно.

## Команды

| Команда | Назначение |
| --- | --- |
| `npm ci` | Установить точные зависимости из lock-файла |
| `npm run build` | Упаковать ассеты, проверить типы и собрать готовый HTML |
| `npm run typecheck` | Подготовить JSON ассетов и проверить строгие типы без выпуска HTML |
| `npm run dev` | Локальный сервер с пересборкой при изменениях; порт 4173, или `PORT` |
| `npm test` | Правила, миграция, Storage, жизненный цикл рейса, границы слоёв |
| `npm run format` | Привести исходники к единому читаемому оформлению |
| `npm run check` | Тесты, проверка типов, сборка и проверка оформления |
| `npm run test:e2e` | Запустить именно готовую сборку в Chromium через `file://`, без сети |

## Чистая проверка перед выпуском

1. Выполнить `npm ci`.
2. Выполнить `npm run check`.
3. Установить браузер `npx playwright install chromium`, если его ещё нет, затем `npm run test:e2e`.
4. Открыть `dist/index.html` и посмотреть оформление. Автотесты также оставляют скриншоты вне репозитория.
5. Проверить `git diff` и сохранить изменения исходников и ассетов коммитом. Результаты сборки в него не включать.

E2E проверяет полный маршрут обучения на 1440×1000 и 390×844: береговой порт, произвольное строительство, дороги, первый рейс, отсутствие рейса без мест, сохранение, отмену и подтверждение сброса. Дополнительно проверяются зажигание маяка, однократное списание 300 монет, сохранение финального письма после перезагрузки и возврат в свободную игру. Он проверяет, что сетевых запросов нет и ошибок JavaScript нет. Это не тест всех устройств, браузеров и драйверов GPU.

## Передача и публикация

Для другого компьютера достаточно одного `dist/index.html`. Для статического хостинга загрузите этот же файл как `index.html`. Серверная логика, база данных и секреты отсутствуют. Никакой публикации сборочный скрипт сам не выполняет.

### GitHub Pages

Публичная игра: https://stray-live-pixel.github.io/streams/.

Workflow `.github/workflows/pages.yml` после push в `main` или текущую ветку `codex/game-menu` устанавливает зависимости через `npm ci`, выполняет `npm run check` и передаёт содержимое `dist/` в GitHub Pages. В `Settings → Pages` выбран источник **GitHub Actions**. Окружение `github-pages` разрешает эти две ветки; последняя успешная публикация обновляет общий сайт. После слияния PR публикация из `main` продолжится автоматически. Запуск вручную доступен через `workflow_dispatch`, когда workflow находится в основной ветке.

Готовые `index.html` и `dist/` остаются вне Git: сборка хранится как артефакт Actions и публикуется через `actions/deploy-pages`. Файл `build.json` на сайте содержит SHA коммита и ветку опубликованной версии. Успешная сборка ещё не означает публикацию: дождитесь зелёного задания `deploy` и проверьте сайт и `build.json`.

При переходе с локального файла на сайт создаётся другая область localStorage. Синхронизация/экспорт городов пока не реализованы. На том же локальном пути сохраняются совместимость ключа и миграция формата.

## Ограничения и диагностика

- Недоступен WebGL 2: включите аппаратное ускорение или используйте другой современный браузер.
- Браузер запрещает localStorage: игра сообщает, что сохранение недоступно; не считайте такой сеанс сохранённым.
- Повреждённое сохранение: показано предупреждение; чтение не стирает запись. Новое действие пользователя начнёт новое сохранение.
- Ошибка установки браузера не означает ошибку сборки: для E2E можно указать `CHROME_PATH` на установленный Chromium/Chrome.
