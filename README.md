# Тихая Гавань

[Играть в браузере](https://stray-live-pixel.github.io/streams/) · [Сборка и публикация](docs/build-and-release.md)

Небольшая 3D-стратегия: постройте порт, дома, фермы и магазины, встречайте корабли с новыми жителями. Время идёт только по кнопке «Следующий день». Цель истории — поселить 50 человек, обеспечить их едой и за 300 монет зажечь маяк. После финального письма город остаётся для свободной игры.

## Просто поиграть

Кнопка **«Письмо Марты»** в главном меню открывает необязательное вступление с портретом, голосом и субтитрами на фоне гавани. Листайте 11 бумажных страниц кнопками или стрелками; номер страницы виден между кнопками: озвучка заканчивается, а текст остаётся. Имя Марты и выход находятся на письме, портрет — у нижнего края экрана. Доступны пауза, повтор и выход через кнопку или Escape. Повторный просмотр всегда начинается сначала и не меняет город.

После клонирования репозитория выполните `npm ci` и `npm run build`: готовые HTML-файлы не хранятся в Git. Если вам уже передали собранный файл, установка не нужна.

Откройте **`index.html`** в браузере. Сначала появится главное меню: «Новая игра» для нового города или «Продолжить» при наличии сохранения. Можно передать этот файл на другой компьютер: JavaScript, Babylon.js, стили, картинки и используемые модели уже внутри. Интернет, Node.js и сервер для игры не нужны.

Игра проверена в современном браузере с WebGL 2 и включённой поддержкой графики. Если графический контекст создать не удалось, страница покажет объяснение. Сохранение хранится в браузере; перенос файла сам по себе не переносит город. У `file://` доступность и привязка localStorage зависят от браузера и пути файла.

В городе нажмите **Escape** или **«Меню · Esc»**: можно вернуться в игру, открыть настройки или выйти в главное меню. На паузе и в главном меню рейс и управление останавливаются; при возврате город продолжит с того же места.

В **настройках** доступны высокое/экономное качество графики, анимация окружения и письма Марты после обучения. Цели и учебные шаги видны всегда. Изменения применяются сразу и сохраняются отдельно от города. Кнопка **«Начать заново»** запрашивает подтверждение, затем запускает новый город с обучением; настройки остаются.

Фон главного меню — 15-секундное зацикленное видео low-poly гавани: камера плавно движется по стабильному участку туда-обратно, вода и мельница оживают. Ролик встроен в автономный HTML, воспроизводится без звука на скорости 0,5× (30 секунд на проход туда и обратно, 24 кадра/с при показе) и останавливается при входе в город или скрытии вкладки. Зажмите мышь на открытом фоне и двигайте влево/вправо, чтобы выбрать ракурс; через 5 секунд после отпускания пролёт продолжится с этого места в направлении последнего жеста. При отключённой анимации, системном уменьшении движения или недоступном видео остаётся исходная иллюстрация. [Промпт и ориентиры визуального стиля](assets/art/README.md) сохранены рядом с [изображением](assets/art/main-menu.webp). Иллюстрация дополняет нынешнюю игровую сцену и служит ориентиром для дальнейшей работы над графикой.

## Редактор 3D-объектов для разработчика

Мастерская запускается отдельно от игры как локальное Node.js-приложение:

```sh
npm ci
npm run editor
```

Откройте `http://127.0.0.1:4174`. Репозиторий должен быть на локальной ветке `main`, чтобы сохранять изменения. Остановка сервера — Ctrl+C; другой порт можно задать через `EDITOR_PORT=4175 npm run editor`.

Слева выберите дом или другую игровую композицию. Справа выбираются её детали, редактируются положение XYZ, поворот в градусах и масштаб по осям. Деталь можно выбрать и на сцене; инструменты «Двигать», «Вращать», «Масштаб» показывают манипуляторы. Кнопка **«Добавить деталь»** открывает каталог Kenney: выберите модель и нажмите **«Добавить в постройку»**. Поддерживаются дублирование, удаление, отмена/повтор и восстановление исходной сборки.

Площадка ограничена **одной игровой клеткой 1×1**: светлый контур — точная граница, внутренняя сетка — шаг 0,1 клетки, центр — `(0, 0)` по X/Z. Камера не меняет масштаб самой геометрии. Выход за границу отмечается над сценой и разрешён, например для крыши или причала; это не увеличивает клетку, занимаемую зданием в игре. Привязка манипуляторов — 0,05 единицы / 15°.

**«Сохранить»** (Ctrl/⌘ S) напрямую записывает `src/objects/templates.json`, создаёт **локальный коммит в `main` только с этим файлом**, затем пересобирает игру. Хеш коммита отображается внизу. Экспорт и сохранение в браузере не нужны. Обновите открытую игру, чтобы увидеть новую геометрию. Файлы, подготовленные вами к другому коммиту, остаются в индексе. Повторное сохранение без изменений не создаёт пустой коммит. Сервер не делает push.

При изменении файла вне редактора устаревшая запись отклоняется. Если Git hook или Git отказывается создавать коммит, исходный файл восстанавливается, а черновик остаётся в редакторе. До успешного сохранения черновики существуют только в текущей вкладке; при закрытии с несохранёнными изменениями браузер предупреждает.

В игре нет кода, интерфейса и полного каталога редактора: в автономный HTML включаются только штатные модели и дополнительные ассеты из сохранённых композиций. Исходные OBJ остаются в `assets/`. Жители, дым и процедурная земля пока доступны в мастерской только для просмотра. Сам редактор собирается отдельно командой `npm run build:editor`.

## Если хотите менять игру

Для разработки установите **Node.js 22 или новее**. В терминале откройте папку проекта:

```sh
npm ci
npm run build
```

Сборка создаст `dist/index.html` и обновит такой же `index.html` в корне. Корневой путь сохранён для игроков, которые уже открывали этот файл и имеют локальное сохранение. Редактировать нужно файлы в `src/`, а не собранный HTML: следующая сборка перезапишет результат.

Для разработки с автоматической пересборкой:

```sh
npm run dev
```

Откройте `http://127.0.0.1:4173`. При изменении исходников файл пересоберётся; обновите вкладку, чтобы увидеть результат. Это простой сервер разработки, а не обязательная часть игры. Его HTTP-сохранение отделено от сохранения открытого через `file://` файла.

## С чего начать чтение

Сюжет, мир, вступительное письмо Марты и этапы истории сохранены в [сюжетной концепции](docs/story.md).

1. [Экскурсия по коду](docs/learning-guide.md) — путь одного клика через всё приложение.
2. [Требования](docs/requirements.md) — что должна делать игра и зачем.
3. [Архитектура](docs/architecture.md) — границы модулей и их маленькие интерфейсы.
4. [Технические решения](docs/decisions.md) — почему выбраны эти технологии и ограничения.
5. [Сборка и выпуск](docs/build-and-release.md) — как проверить и передать результат.

```text
src/
  main.ts             Соединяет модули, сохраняет результаты, доставляет события
  domain/             Правила города, экономика, обучение и состояние
  persistence/        Чтение и запись сохранений через переданный Storage
  objects/            Конфигурации 3D-композиций и их валидация
  editor/             Локальный Node.js-сервер, Git-сохранение и интерфейс мастерской
  ui/                 Письма Марты, HTML, тема theme.css, расположение и кнопки
  input/              Клики, перетаскивание, колесо, клавиатура
  scene/              Babylon.js, композиции Kenney, камера и анимация рейса
scripts/              Сборка, упаковка ассетов и сервер разработки
assets/               Полные исходные наборы Kenney, лицензии, manifest
tests/               Проверки правил, границ модулей и готового HTML
```

`index.html`, `.generated/` и `dist/` — производные файлы, исключённые из Git. Все исходные ассеты из `assets/` хранятся в репозитории. Историю версий хранит Git; копии `version-N.html` не создаются.

## Проверки

```sh
npm run check       # Тесты правил и архитектуры, проверка типов, сборка и форматирование
npm run test:e2e    # Готовый HTML через file://, без сети, на двух размерах экрана
```

Для второго шага нужен браузер Playwright: `npx playwright install chromium`. На macOS тест также умеет использовать установленный Google Chrome; на другой системе можно задать `CHROME_PATH`. Скриншоты тестов сохраняются во временной папке операционной системы, путь печатается в результате.

## Технологии и лицензии

- TypeScript: явные контракты команд и состояния, строгая проверка перед сборкой.
- Babylon.js: камера, геометрия, материалы и управление WebGL.
- esbuild: объединение модулей в автономный HTML.
- Node.js test runner с tsx и Playwright: логика без браузера и проверка настоящей игры.
- [Kenney Fantasy Town Kit](https://kenney.nl/assets/fantasy-town-kit) и [Pirate Kit](https://kenney.nl/assets/pirate-kit): CC0; оригинальные лицензии внутри `assets/`.
- Babylon.js: Apache-2.0. Текст его лицензии включается в готовый HTML и описан в [NOTICE.md](NOTICE.md).

## Как изменить оформление

Откройте `src/ui/theme.css`: `--color-paper` задаёт бумагу, `--color-ink` — основной текст, `--color-accent` — печати и выделение, `--color-primary` — основные кнопки. Цвета, шрифты, радиусы и тени используются всеми компонентами. Позиции и адаптация к экрану находятся в `src/ui/styles.css`. После изменения выполните `npm run build`.

Типы команд и города находятся в `src/domain/types.ts`. Расширение `.js` в путях `import` намеренно: TypeScript и tsx сопоставляют эти пути исходным `.ts`, а браузер получает уже собранный JavaScript. Отдельно проверить типы можно командой `npm run typecheck`.
