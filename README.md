# Тихая Гавань

Небольшая 3D-стратегия: постройте порт, дома, фермы и магазины, встречайте корабли с новыми жителями. Время идёт только по кнопке «Следующий день».

## Просто поиграть

Откройте **`index.html`** в браузере. Можно передать этот файл на другой компьютер: JavaScript, Babylon.js, стили, картинки и используемые модели уже внутри. Интернет, Node.js и сервер для игры не нужны.

Игра проверена в современном браузере с WebGL 2 и включённой поддержкой графики. Если графический контекст создать не удалось, страница покажет объяснение. Сохранение хранится в браузере; перенос файла сам по себе не переносит город. У `file://` доступность и привязка localStorage зависят от браузера и пути файла.

## Если хотите менять игру

Для разработки установите **Node.js 22 или новее**. В терминале откройте папку проекта:

```sh
npm ci
npm run build
```

Сборка создаст `dist/index.html` и обновит такой же `index.html` в корне. Корневой путь сохранён для игроков, которые уже открывали этот файл и имеют локальное сохранение. Редактировать нужно файлы в `src/`, а не собранный HTML: следующая сборка перезапишет результат.

Для разработки с автоматической пересборкой:

```sh
npm run dev
```

Откройте `http://127.0.0.1:4173`. При изменении исходников файл пересоберётся; обновите вкладку, чтобы увидеть результат. Это простой сервер разработки, а не обязательная часть игры. Его HTTP-сохранение отделено от сохранения открытого через `file://` файла.

```text
src/
  main.ts             Соединяет модули, сохраняет результаты, доставляет события
  domain/             Правила города, экономика, обучение и состояние
  persistence/        Чтение и запись сохранений через переданный Storage
  ui/                 Письма Марты, HTML, тема theme.css, расположение и кнопки
  input/              Клики, перетаскивание, колесо, клавиатура
  scene/              Babylon.js, композиции Kenney, камера и анимация рейса
scripts/              Сборка, упаковка ассетов и сервер разработки
assets/               Полные исходные наборы Kenney, лицензии, manifest
tests/               Проверки правил, границ модулей и готового HTML
```

`.generated/` и `dist/` — производные файлы, исключённые из Git. Историю версий хранит Git; копии `version-N.html` не создаются.

## Проверки

```sh
npm run check       # Тесты правил и архитектуры, проверка типов, сборка и форматирование
npm run test:e2e    # Готовый HTML через file://, без сети, на двух размерах экрана
```

Для второго шага нужен браузер Playwright: `npx playwright install chromium`. На macOS тест также умеет использовать установленный Google Chrome; на другой системе можно задать `CHROME_PATH`. Скриншоты тестов сохраняются во временной папке операционной системы, путь печатается в результате.

## Технологии и лицензии

- TypeScript: явные контракты команд и состояния, строгая проверка перед сборкой.
- Babylon.js: камера, геометрия, материалы и управление WebGL.
- esbuild: объединение модулей в автономный HTML.
- Node.js test runner с tsx и Playwright: логика без браузера и проверка настоящей игры.
- [Kenney Fantasy Town Kit](https://kenney.nl/assets/fantasy-town-kit) и [Pirate Kit](https://kenney.nl/assets/pirate-kit): CC0; оригинальные лицензии внутри `assets/`.
- Babylon.js: Apache-2.0. Текст его лицензии включается в готовый HTML и описан в [NOTICE.md](NOTICE.md).

## Как изменить оформление

Откройте `src/ui/theme.css`: `--color-paper` задаёт бумагу, `--color-ink` — основной текст, `--color-accent` — печати и выделение, `--color-primary` — основные кнопки. Цвета, шрифты, радиусы и тени используются всеми компонентами. Позиции и адаптация к экрану находятся в `src/ui/styles.css`. После изменения выполните `npm run build`.

Типы команд и города находятся в `src/domain/types.ts`. Расширение `.js` в путях `import` намеренно: TypeScript и tsx сопоставляют эти пути исходным `.ts`, а браузер получает уже собранный JavaScript. Отдельно проверить типы можно командой `npm run typecheck`.
